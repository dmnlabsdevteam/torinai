# Contributing to Decentralized Logging and Monitoring System

Thank you for your interest in contributing to the Decentralized Logging and Monitoring System! Here are some guidelines to help you get started:

## How to Contribute
1. Fork the repository and create a new branch:
   ```bash
   git checkout -b your-branch-name
   ```
2. Make your changes and commit them:
   ```bash
   git commit -m "Your commit message"
   ```
3. Push your changes to your fork:
   ```bash
   git push origin your-branch-name
   ```
4. Create a pull request on GitHub.

## Code Style
- Follow PEP 8 for Python code.
- Use clear and concise commit messages.

## Testing
- Ensure all tests pass before submitting a pull request.
- Add new tests for new features or bug fixes.

## Security
- Report any security issues immediately to security@yourdomain.com.
